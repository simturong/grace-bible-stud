# 📋 은혜 성경공부 웹앱 세부 구현 계획서 (implementation_plan.md)

본 문서는 부모님을 위한 성경 공부 웹앱의 벤치마킹 조사 결과, 기술 아키텍처 정의, 기능 설계 및 배포 계획을 담은 핵심 기획서입니다. 유저의 승인 하에 지속적으로 업데이트됩니다.

---

## 🔍 1. 시장 조사 및 벤치마킹 (Benchmarking Analysis)

구글 플레이스토어에서 가장 평점이 높고 어르신들이 많이 사용하는 인기 성경 앱 3종을 분석하여 본 프로젝트에 반영할 시사점을 도출했습니다.

### 📊 1-1. 대표 성경 앱 분석
1. **다번역성경찬송 (대한성서공회/기독교서회 제공 등)**
   - **강점**: 다양한 번역본(개역개정, 쉬운성경, NIV)의 동시 비교, 오디오 성경(낭독) 제공.
   - **단점**: 광고가 많고 UI가 너무 빽빽하여 시력이 약한 어르신들이 메뉴를 찾기 힘듦.
2. **매일 성경 묵상 (Quiet Time)**
   - **강점**: 매일 한 구절씩 정갈한 디자인으로 띄워주며 알림을 보냄.
   - **단점**: 성경 전체를 검색해서 심화 학습을 하거나 퀴즈, 필사를 해보는 능동적 기능 부족.
3. **말씀 쓰기 (성경 필사 전용 앱)**
   - **강점**: 자판으로 입력하며 타이핑 정확도를 체크해 주는 필사 특화.
   - **단점**: 터치펜으로 그리기(캘리그래피 방식) 기능이 없거나 분리되어 있음.

### 💡 1-2. 우리 앱의 차별화 포인트 (Benchmarking Takeaways)
* **광고와 복잡한 메뉴 제거**: 단 4개의 하단 탭만 배치하여 터치 오작동 방지.
* **하이브리드 학습 스위치**: 
  - **콘텐츠**: `매일 성경 묵상 (오늘의 말씀)` (매일 아침 은혜로운 대표 구절과 따뜻한 묵상 에세이 제공) ➡️ `정독 모드` (성경 66권 전체 뷰어)의 쉬운 전환.
  - **필사**: `타이핑 자판 모드`와 터치 및 스마트 펜을 활용한 `손글씨 드로잉 캔버스 모드`를 탭으로 동시 지원.
  - **보조 기능**: 글자 크기 3단계 변경 뿐 아니라, 화면에 깔리는 본문을 음성으로 친절하게 읽어주는 **TTS(낭독) 플레이어**를 하단에 상시 탑재.

## 🛠️ 2. 데이터 확보 및 아키텍처 설계

### 2-1. 전체 성경 데이터베이스 확보 방안
성경 데이터베이스(구약 39권, 신약 27권 전체 장/절)는 별도의 데이터베이스 서버(MySQL 등)를 두면 비용과 관리 문제가 발생하므로, **서버리스 및 오프라인 구동을 극대화하기 위해 정적 JSON 데이터 파일**로 컴파일하여 클라이언트에 내장합니다.
* **데이터 포맷**: `bible_ko_kr.json` (개역개정 혹은 현대인의 성경 기준, 용량 약 4.5MB 내외로 모바일 다운로드에 부담 없음)
* **소스**: 퍼블릭 도메인으로 공개된 성경 정적 데이터 소스(Github Open Source Bible data)를 활용하여 정제 후 적용.
* **매일 성경 묵상 데이터 연동**: 66권 전체 성경 데이터 외에, 1년 365일 매일 날짜에 매칭되어 보여줄 **묵상 본문용 구절 및 묵상글 메타 데이터**를 분리하여 경량 내장합니다.

## 🎙️ 3. 고품질 AI 음색 개편 & 디스플레이 오프(백그라운드) 및 다음 장 자동 연속 낭독 아키텍처

기존의 단순 브라우저 기계음 방식과 화면 슬립 모드 시 낭독이 즉각 차단되는 모바일 브라우저의 한계를 돌파하기 위해, **고품질 AI 자연어 음성 매핑, 무음 웨이크 락(Silent Wake Lock) 백그라운드 구동, 그리고 다음 장으로의 자동 이동 연쇄 낭독** 기술을 아래와 같이 결합 설계합니다.

### 🎧 3-1. 뚝뚝 끊기는 기계음 해결: 고품질 AI 자연어 보이스(Natural Online Voice) 매핑
브라우저의 기본 여성/남성 기계음이 매우 어색하고 기기나 OS(윈도우, iOS, 안드로이드)에 따라 남성 보이스 변경이 아예 무시되거나 끊기는 문제를 해결하기 위해 **AI 신경망 성우 보이스**를 지능적으로 선별합니다.
1. **온라인 자연어 AI 음색(Natural Voices) 적극 탐색**:
   - `window.speechSynthesis.getVoices()`로 사용 가능한 음성 목록을 긁어올 때, 한국어(`ko-KR`) 보이스 중 Microsoft의 클라우드 신경망 목소리(예: `Microsoft InJoon Online (Natural) - Korean` 남성 낭독자, `Microsoft SunHi Online (Natural) - Korean` 여성 낭독자) 혹은 Google의 자연어 보이스가 존재한다면 이를 최우선으로 탐색하여 지정합니다.
   - 이 온라인 내츄럴 보이스는 사람 성우와 구분이 되지 않을 정도로 **대단히 매끄럽고 은혜로운 낭독 톤**을 제공합니다.
2. **폴백(Fallback) 목소리 튜닝**:
   - 디바이스가 오프라인이거나 구형 기기여서 자연어 보이스를 사용할 수 없는 경우, 기기 내장 네이티브 한국어 기본 음성의 `pitch`와 `rate`를 정교하게 리디자인하여 쇳소리와 뚝뚝 끊기는 느낌을 최소화합니다.
3. **구글 번역 고품질 오디오 API (Hybrid Option)**:
   - 클라이언트에서 최선의 자연어 보이스가 매핑되지 않는 특정한 모바일 웹 브라우저 환경을 대비해, 구글 번역 고품질 스트리밍 음색 주소(`https://translate.google.com/translate_tts?ie=UTF-8&tl=ko&client=tw-ob&q=텍스트`)로 즉시 폴백하여 HTML5 `Audio` 객체로 부드럽게 미디어 음원을 재생할 수 있도록 유연한 하이브리드 어댑터 패턴을 구현합니다.

### 📱 3-2. 휴대폰 디스플레이 오프(잠금화면) 및 백그라운드 낭독 보장 아키텍처
스마트폰의 화면이 꺼지거나 화면이 잠기면(슬립 모드), 모바일 OS(Android, iOS)의 배터리 절약 정책 때문에 웹 브라우저의 JavaScript 작동이나 Web Speech API 낭독 프로세스가 강제로 차단(킬)됩니다. 이를 극적으로 우회하기 위해 두 가지 핵심 기술적 방어책을 동시에 구동합니다.

1. **`Media Session API` (`navigator.mediaSession`) 공식 연동**:
   - 스마트폰 시스템 오디오 컨트롤과 완전하게 상호작용하도록 브라우저 오디오 세션을 정식 등록합니다.
   - 화면이 꺼진 잠금 화면 상태에서도 현재 낭독 중인 성경 구절 정보(예: `시편 23편 1절 낭독 중`)를 곡명/아티스트 정보로 띄우고, 앨범 아트로 멋진 교회의 로고를 노출합니다.
   - 시스템 잠금 화면 제어기(이전 곡, 다음 곡, 일시정지, 재생)를 연결하여 화면이 꺼진 상태에서도 낭독의 앞뒤 스킵과 재생/정지가 완전히 가능해집니다.
2. **무음 웨이크 락 (Silent Audio Wake Lock - 백그라운드 프리벤트)**:
   - 스마트폰 화면이 꺼지는 순간 시스템이 브라우저의 백그라운드 재생 포커스를 뺏고 웹앱을 일시 정지(Freeze)시키는 동작을 방어하기 위해, 재생 시 **아주 짧은 1초 미만의 고음질 무음(Silent) 오디오 트랙을 HTML5 `Audio` 객체로 로드하여 무한 반복 재생(`.loop = true`)**시킵니다.
   - 이를 통해 안드로이드 및 iOS OS는 이 웹앱을 "현재 음악을 연속 재생 중인 고정 미디어 앱"으로 간주하게 되며, 화면 슬립 모드에 진입하더라도 낭독 루프(`speechSynthesis` 또는 `gTTS Audio`) 프로세스를 전혀 죽이지 않고 1절부터 마지막 절까지 완벽하게 백그라운드 음성 송출을 유지시킵니다.

### 🔁 3-3. 장 내 1절~끝절 및 다음 장(Chapter) 자동 이어서 연속 낭독 메커니즘
현재 묵상 본문이나 한 구절 단위로 끊기던 플레이어를 성경 66권 전체 낭독 시 **쉬지 않고 다음 장으로 연쇄 정주행하는 라우터 엔진**으로 개편합니다.

1. **장 내 구절 간 연쇄 낭독 (Continuous Verse Queue)**:
   - 한 절의 낭독 음성이 자연스럽게 끝나면(`onend`), 스크립트가 0.7초의 은혜로운 여백(숨 고르기 pause) 후 다음 구절 엘리먼트를 자동으로 추적하여 `.verse` 액션 선택 및 하이라이트 효과와 함께 재생 큐를 이어갑니다.
2. **장의 끝 도달 시 다음 장 자동 로딩 & 연속 낭독 (Next Chapter Auto-Routing)**:
   - 현재 읽고 있는 성경의 마지막 절(예: 시편 23편 6절)의 낭독이 끝나면:
     - **'오늘의 묵상(meditation)' 탭**인 경우: 묵상 완독이 목적이므로 기존처럼 따뜻한 완료 칭찬 팝업(`alert`)을 띄우고 재생을 종료합니다.
     - **'성경 공부/정독(reading)' 탭**인 경우: 멈추지 않고 즉시 다음 장(예: 시편 23편 ➔ 시편 24편 1장) 또는 현재 책의 마지막 장인 경우 다음 책의 1장(예: 마태복음 28장 끝 ➔ 마가복음 1장 1절)으로 데이터를 자동 갱신 로드(`loadBiblePassage(nextBookId, nextChapterNum)`)합니다.
     - 로드가 완료되는 즉시, 새로 로드된 장의 1절을 타겟팅하여 자동으로 낭독 재생을 트리거합니다.
   - 이를 통해 어머님, 아버님께서 스마트폰을 틀어놓고 밭일을 하시거나 눈을 감고 편안히 휴식하실 때에도 손 하나 까딱하지 않고 신약성경 전체를 연속으로 완독하실 수 있는 완벽한 라디오형 입체 낭독 서비스로 탈바꿈합니다.

## 🔑 4. 구글 로그인 및 데이터 백엔드 아키텍처

부모님이 언제 어디서든 스마트폰을 바꾸거나 컴퓨터로 접속해도 말씀 확인 이력, 성경 공부 책갈피, 말씀 필사 진행도를 안전하게 보존하고 조회할 수 있도록 **구글 OAuth(Google Login)와 Firebase 서버리스 데이터베이스**를 연동합니다.

### 4-1. 기술 및 데이터베이스 설계
*   **인증(Authentication)**: `Firebase Auth` + `구글 간편 로그인(Google Provider)`. 부모님들께서 비밀번호를 별도로 메모하거나 기억하실 필요 없이, 버튼 한 번만 터치하면 연동되어 안전하고 스트레스가 없습니다.
*   **데이터베이스(Firestore)**: Google 클라우드의 NoSQL 데이터베이스인 `Cloud Firestore`를 활용하여 아래와 같은 경량의 스키마로 설계합니다. Vercel 배포 시 Firebase 무료 티어(하루 읽기 5만 회, 쓰기 2만 회)로 평생 무상 운영이 완벽히 가능합니다.

## 📱 5. 구체적 프론트엔드 기능 구현 명세 (Core Feature Specifications)

현재 데모에서 미흡했던 부분을 완벽히 보완하고 기획 의도와 부합하도록 실질적인 화면 구성 요소를 다음과 같이 정의하여 개발에 순차적으로 적용합니다.

### 5-1. [화면 1] 매일 성경 묵상 (오늘의 말씀 - 최우선 메인 화면)
*   **배치**: 어플리케이션 접속 시 나타나는 최초의 메인 뷰.
*   **구성 요소**:
    - **오늘의 날짜 뱃지**: 예) "2026년 5월 31일 주일 아침"
    - **오늘의 묵상 구절 카드**: 엄선된 구절이 큼직한 명조체와 따뜻한 골드 장식선과 함께 중앙에 노출.
    - **절별 개별 재생 스위치**: 구절 옆에 🔊 아이콘 배치 (터치 시 해당 구절만 실시간 하이라이팅되며 음성 낭독).
    - **오늘의 묵상 생각**: 그날 말씀의 쉬운 현대어 풀이와 부모님 마음에 와닿을 은혜로운 묵상 에세이 글 노출.
    - **[오늘의 성경 공부로 이어가기] 버튼**: 묵상을 다 마친 어르신을 다음 탭(성경 공부)으로 스무스하게 유도하는 크고 둥근 액션 버튼.

### 5-2. [화면 2] 구약/신약 66권 전체 성경 뷰어 (선택 및 정독)
*   **배치**: 하단 2번째 탭 "성경 공부/정독" 화면.
*   **구성 요소**:
    - **66권 선택 패널**:
      * [구약] / [신약]을 큼직한 토글 단추로 선택.
      * 구약 선택 시 (창세기부터 말라기까지 39권), 신약 선택 시 (마태복음부터 요한계시록까지 27권) 책 이름이 바둑판형의 큼직한 버튼 카드로 배열되어 터치하기 쉬움.
      * 책 선택 시 해당 책의 [1장, 2장...] 장번호가 슬라이더 휠 형태로 스무스하게 선택 가능.
    - **정독 뷰어 화면**:
      * 선택 완료 즉시 해당 장의 전체 구절(1절부터 끝절까지)이 로딩되어 화면에 배열됨.
      * 각 구절 좌측에 개별 재생 `🔊` 단추가 달려 있어 듣고 싶은 절을 선택해 낭독 청취 가능 (읽어주는 줄은 실시간으로 형광 펜으로 짚어주듯 골드 배경색으로 자동 빛남).
      * 이 뷰어에서 현재 읽고 있는 마지막 장/절 위치가 구글 로그인 계정 정보(Firebase)에 **"책갈피"**로 실시간 영구 자동 보존됨.

### 5-3. [화면 3] 하단 고정형 럭셔리 오디오 컨트롤러 플레이 바 (Floating Audio Controller)
*   **배치**: 모든 화면(묵상, 성경 공부)에서 하단 탭 바 바로 위에 은은하게 플로팅(Glassmorphism)되어 상시 노출되는 오디오 제어 허브.
*   **구성 요소**:
    - **낭독 구절 상태 정보**: 좌측에 "📖 시편 23편 1절 낭독 중..." 또는 멈춤 시 "은혜의 말씀 대기 중" 표시.
    - **큼직한 제어 버튼**: 어르신들이 터치하기 쉬운 직관적인 **[▶ 재생 / ⏸ 일시정지]** 및 **[⏭ 다음 구절로]** 물리형 원형 버튼 배치.
    - **실시간 금빛 리본 진행바 (Progress Line)**: 낭독되고 있는 글자 수/시간 비율에 맞춰 바닥면을 따라 금빛 그라데이션 선이 흐르듯 채워짐.
    - **목소리 기어 단추 (`⚙️`)**: 5가지 따뜻한 한국어 목소리 프리셋(온화한 어머니, 인자한 아버지 등)을 즉시 팝업으로 골라 변경할 수 있는 편리한 스케일 버튼.

### 5-4. [화면 4] 드로잉 캔버스 & 타이핑 말씀 필사
*   **배치**: 하단 3번째 탭 "말씀 필사" 화면.
*   **구성 요소**:
    - 현재 성경 공부 탭에서 고른 장/절 또는 오늘의 묵상 구절이 상단 필사 가이드라인 영역에 흐릿한 글자 서체로 깔림.
    - **손글씨 모드**: 태블릿 펜이나 손가락으로 화면에 포레스트 그린 색 잉크 브러시로 글씨를 따라 적음.
    - **타이핑 모드**: 키패드로 타이핑하면 한 글자씩 매칭(다음 쓸 글자는 깜빡임) 검증.
    - **[필사 완료] 직접 터치 버튼**: 큼직하고 둥글게 하단 배치. 완료 시 부모님께 무한한 자긍심을 주는 따뜻한 축하 칭찬 메시지 창 표출.

### 5-5. [화면 5] 은혜 성경 퀴즈
*   **배치**: 하단 4번째 탭 "성경 퀴즈" 화면.
*   **구성 요소**:
    - 오늘 공부한 장/절에 대한 3지선다형 성경 인물/교리 객관식 퀴즈 1문항 자동 출제.
    - 정답 클릭 시 초록색 변환 및 "참 잘하셨습니다!" 스티커 수여.
    - 오답 클릭 시 빨간색 변환 및 "다시 한번 기도하는 마음으로 읽어보세요! 화이팅!" 이라는 위트 있는 격려 메시지 상자 팝업.
