# 📖 은혜 성경공부 웹앱 상세 설계 사양서 (design.md)

본 문서는 `using-superpowers` 및 `brainstorming` 스킬 프로토콜에 따라 유저와 1:1 상호 의사결정을 통해 최종 확정된 **"은혜 성경공부" PWA 웹앱**의 상세 사양 스펙 명세서입니다.

## 🎯 1. 제품 개념 및 정의 (Product Definition)
*   **제품명**: 은혜 성경공부 (의정부중앙교회 전용)
*   **유형**: 설치가 필요 없는 모바일 최적화 점진적 웹앱 (PWA - Progressive Web App)
*   **배포 환경**: Vercel (정적 웹 호스팅)
*   **타겟 사용자**: 의정부중앙교회 교우 및 시니어 부모님 (어머니, 아버지)

---

## 🛠️ 2. 최종 확정된 3대 핵심 스펙 (Core Specifications)

### 2-1. [번역본 전환] 개역개정 4판 및 개역한글 최신판 실시간 비교 선택
*   **지원 번역본**:
    - **개역개정 4판 (한글 개역개정)**: 현재 강단에서 널리 쓰이는 표준 성경.
    - **개역한글 최신판 (한글 개역한글)**: 부모님 세대에 가장 친숙하고 깊이 있는 전통 성경.
*   **비교 UI**: 성경 읽기 뷰어 상단에 큼직한 [개역개정] ↔ [개역한글] 토글 스위치를 장착하여, 터치 즉시 해당 구절의 번역 텍스트가 0.1초 만에 스위칭 연동.

### 2-2. [장선택 패널] 구약/신약 66권 대분류 및 "장(Chapter) 바둑판" 네비게이션
*   **대분류 구조**: 구약(39권) / 신약(27권) 카드 배열 그리드.
*   **장(Chapter) 펼침 흐름**:
    - 예) **[창세기]** 카드를 클릭하면, 화면 이동 대신 그 자리에서 창세기의 전체 장수(50장)가 큼직한 **장번호 바둑판 버튼판(1, 2, 3 ... 50)** 형태로 아코디언처럼 아래로 스무스하게 펼쳐짐.
    - 부모님이 장번호(예: 23)를 콕 누르면, 그제야 [성경 읽기] 화면으로 넘어가 창세기 23장의 1절부터 끝절까지의 본문이 정밀 로드됨.
    - 뷰어 최상단에는 **"↩️ 다른 장/책 선택하기"** 버튼을 제공하여 책/장 선택을 극도로 자유롭게 조율.

### 2-3. [남/여 2종 사람 목소리 TTS] 기계음을 전면 배제한 고품질 한국어 TTS
*   **목소리 유형**:
    - **자상한 자매님 (여성 낭독자)**: 차분하고 나긋나긋하며 끝 발음 처리가 자상한 성우 톤.
    - **인자한 형제님 (남성 낭독자)**: 예배 낭독에 최적화된 신뢰성 있고 경건한 중저음 톤.
*   **기술**: Web Speech API Neural Ko Voices 및 gTTS-Ko 고성능 음성 엔진 브릿지를 매칭하여, 기계 특유의 쇳소리를 전면 배제하고 실제 사람이 나란히 서서 짚어 읽어주는 듯한 은혜로운 사운드 출력.
*   **구절 시각적 추적 (Sentence Highlighting)**: 오디오가 읽어주는 구절이 눈앞에서 들이쉬고 내쉬는 펄스 주기로 부드럽게 반짝이는 `holyHaloGlow` 금빛 후광 애니메이션 연동.
